# Background audio assets

Place 2–3 royalty-free tracks in this folder and reference them in:
- `src/app/config/audioTracks.js`

Expected paths:
- `/public/audio/<filename>.mp3` → served as `/audio/<filename>.mp3`

Recommended sources (royalty-free / no-copyright):
- Pixabay Music (Jazz / Hip-hop / Hip-hop Jazz search)
- InAudio
- Uppbeat
- Free Music Archive
- Bensound Jazz

Suggested safe filenames (examples used by the config):
- `lofi-jazz-01.mp3`
- `hiphop-beat-01.mp3`
- `hiphop-jazz-01.mp3`
